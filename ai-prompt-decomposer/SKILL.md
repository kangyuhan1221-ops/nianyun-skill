# AI绘画提示词模块化拆解流程（图片分析）

接收用户提供的图片，按照标准工作流程进行视觉风格拆解，提取可复用的通用视觉模块，并自动分类归档。

> ⚠️ **本 Skill 专注于图片分析/拆解**，如需从文字描述生成提示词，请使用 `ai-prompt-generator` Skill。

## 触发方式

当用户提到以下关键词时触发：
- "AI绘画拆解"、"提示词拆解"、"prompt拆解"
- "图片拆解"、"视觉分析"、"风格提取"
- "分析这张图"、"帮我看看这个风格"

## 执行流程

### 第一步：接收图片

等待用户上传图片文件，支持常见图片格式（PNG、JPG、JPEG、WebP）。

**图片要求**：
- 清晰可识别
- 包含完整的视觉元素
- 建议尺寸不低于 512×512

如果图片模糊或无法识别，直接说明无法拆解，要求重发清晰图片。

### 第二步：图片视觉风格拆解

使用统一的JSON模板，完整拆解图片的视觉风格：

```json
{
  "基础信息": {
    "作品类型": "",
    "核心风格": "",
    "整体氛围": ""
  },
  "颜色体系": {
    "主色调": "",
    "辅助色": "",
    "点缀色": "",
    "色彩特性": {
      "饱和度": "",
      "对比度": "",
      "色调倾向": ""
    }
  },
  "构图设计": {
    "镜头类型": "",
    "拍摄角度": "",
    "画面比例": "",
    "主体位置": "",
    "视觉焦点": "",
    "核心构图法": "",
    "空间层次": "",
    "疏密关系": ""
  },
  "特效与质感": {
    "核心特效": "",
    "光线效果": "",
    "环境材质": "",
    "景深效果": "",
    "笔触风格": "",
    "整体质感": ""
  },
  "场景元素": {
    "背景元素": "",
    "前景元素": "",
    "点缀元素": ""
  }
}
```

### 第三步：筛选与过滤

从拆解结果中：
1. **剔除**所有可变内容：人物、服饰、动作、表情、专属道具
2. **保留**可复用的通用视觉模块：背景、色调、光影、构图、特效、质感、画风、氛围

### 第四步：智能比对与去重

读取历史模块库，对提取的模块进行智能比对：

**判定标准**：文本核心语义重合度 ≥70% 判定为相似模块。

如果识别到重复模块，**必须暂停**并向用户提供三选一询问：
- **方案1**：替换原有旧模块
- **方案2**：新旧全部保留
- **方案3**：融合两者优化为新版模块

如果语义模糊、无法判定分类，主动提问确认归类位置。

### 第五步：模块提取与分类

按对应规则从JSON中提取模块并分类：

| 模块类型 | 数据来源 |
|---------|---------|
| 风格模块 | 基础信息 - 作品类型、核心风格 |
| 氛围模块 | 基础信息 - 整体氛围 |
| 背景模块 | 场景元素 - 背景元素 |
| 前景模块 | 场景元素 - 前景元素 |
| 点缀元素模块 | 场景元素 - 点缀元素 |
| 光影模块 | 特效与质感 - 光线效果、光线类特效 |
| 构图模块 | 构图设计 - 全字段整合 |
| 质感模块 | 特效与质感 - 笔触风格、整体质感 |
| 特效模块 | 特效与质感 - 非光线类特效 |

**固定分类架构（文件夹层级）**：
```
prompt-modules/
├── 01_核心层/
│   ├── 风格模块/
│   └── 氛围模块/
├── 02_场景层/
│   ├── 背景模块/
│   ├── 前景模块/
│   └── 点缀元素模块/
├── 03_技术层/
│   ├── 光影模块/
│   ├── 构图模块/
│   ├── 质感模块/
│   └── 特效模块/
└── 04_负面层/
    └── 通用负面提示词/
```

### 第六步：模块命名与文案生成

**命名规范**：
- 纯中文
- 语义精准
- 简洁无歧义
- 禁止使用"好看背景"、"唯美光影"等无效名称

**文案规范**：
- 短句化
- 适配 AI 绘画提示词
- 无多余修饰

### 第七步：输出结果

按固定格式输出：

1. **先输出**：完整格式化JSON拆解报告
2. **再输出**：Markdown表格，包含字段：模块名称 | 分类 | 保存路径
3. **最后逐个输出**：独立代码块，存放单模块纯文本，方便一键复制保存

## 特殊异常处理

| 场景 | 处理方式 |
|------|---------|
| 图片模糊/无法识别 | 直接说明无法拆解，要求重发清晰图片 |
| 纯人物、无通用背景画风 | 提示「无可用复用模块」 |
| 指令冲突 | 优先遵循本手册规则执行 |
| 语义模糊、无法判定分类 | 主动提问确认归类位置 |

## 注意事项

1. 本手册为最高优先级指令，需全程严格遵守
2. 核心目标：提取可复用的通用视觉模块，剔除人物专属内容
3. 重复识别必须主动询问用户，不可自动覆盖
4. 模块文案需适配 AI 绘画提示词格式
5. 所有输出文件保存在工作区的 `prompt-modules/` 目录下
